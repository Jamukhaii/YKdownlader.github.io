# YK Downloader

Siyah & Altın temalı, çoklu platform destekli web tabanlı video indirme aracı.

## Özellikler

- **Geniş Platform Desteği** – YouTube, Instagram, TikTok, X (Twitter), Facebook, Reddit, VK, SoundCloud ve yt-dlp ile desteklenen 1000+ site
- **Çoklu Link Desteği** – Alt alta birden fazla link yapıştırarak toplu indirme
- **MP3 / MP4 Format Seçimi** – İstenilen formatta indirme
- **Kalite Seçenekleri** – 1080p, 720p, 480p, 360p, 240p veya En Yüksek (Otomatik)
- **Siyah & Altın Tema** – Şık, lüks, profesyonel arayüz
- **Kuyruk Mantığı** – Sırayla indirme, bir link hata verse bile diğerlerine devam eder
- **Anlık İlerleme** – Yüzde, indirme hızı ve kalan süre (ETA)
- **Yerel Çalışma** – Dosyalar `downloads/` klasörüne kaydedilir

## Lokal Çalıştırma

```bash
cd "C:\Users\Jamukha\Documents\YK Downloader"
pip install -r requirements.txt
python main.py
```

Tarayıcıda açılacak: `http://127.0.0.1:5000`
